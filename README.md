# Fiverr Time Tracker

**Fiverr Time Tracker** is a Chrome extension designed to automatically monitor and record the time you spend on [Fiverr](https://www.fiverr.com/). This tool helps freelancers and professionals track their online activity, promoting better time management and productivity.

---

## Features

- **Automatic Time Tracking**: Begins tracking as soon as you access any page on Fiverr.
- **Real-Time Monitoring**: Continuously monitors your active session on Fiverr.
- **Idle Detection**: Pauses tracking when the browser is inactive or the system is idle.
- **Data Persistence**: Saves your tracked time locally, ensuring data is retained across sessions.
- **User Interface**: Provides a popup to view and reset your tracked time.
